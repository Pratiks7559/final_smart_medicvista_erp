Deployment Reference

Set these on the wholesaler server to switch modes without touching code:

# LOCAL (same LAN) RETAILER_SYNC_MODE=LOCAL RETAILER_SYNC_SERVER_URL=http://192.168.1.100:8000 # CLOUD (internet HTTPS) RETAILER_SYNC_MODE=CLOUD RETAILER_SYNC_SERVER_URL=https://erp.company.com
